1. Stack Completa

Todas as tecnologias do guideline transversal se aplicam. As adições específicas desta abordagem estão destacadas.

SonarQube Community Análise estática de complexidade. Transversal

2. RabbitMQ

O RabbitMQ é o único componente de infraestrutura exclusivo desta abordagem. Ele é o canal de comunicação assíncrona entre a Write App e a Read App.

⚠
A Write App só publica na fila após confirmar a persistência no Event Store. Nunca o contrário. Ver guideline de negócio — seção Command Handlers.
ℹ
A tag management do RabbitMQ habilita o painel web em localhost:15672 (usuário e senha: guest). Útil para inspecionar filas e mensagens durante o desenvolvimento.

3. Aplicações

AplicaçãoPortaResponsabilidade
Write App 8080 Recebe commands, executa aggregates, persiste no Event Store, publica eventos no RabbitMQ.
Read App 8081 Consome eventos do RabbitMQ, atualiza projeções, serve queries. Nunca escreve no Event Store.

5. Docker Compose

docker-compose.ymlYAML
services:

  # ── Banco de escrita (Event Store) ───────────────────
  db-write:
    image: postgres:16
    container_name: crm-db-write
    environment:
      POSTGRES_DB: crm_write
      POSTGRES_USER: crm
      POSTGRES_PASSWORD: crm
    ports:
      - "5432:5432"
    networks:
      - crm-network

  # ── Banco de leitura (Projeções) ─────────────────────
  db-read:
    image: postgres:16
    container_name: crm-db-read
    environment:
      POSTGRES_DB: crm_read
      POSTGRES_USER: crm
      POSTGRES_PASSWORD: crm
    ports:
      - "5433:5432"
    networks:
      - crm-network

  # ── RabbitMQ ─────────────────────────────────────────
  rabbitmq:
    image: rabbitmq:4-management
    container_name: crm-rabbitmq
    ports:
      - "5672:5672"  # AMQP
      - "15672:15672" # Management UI
    networks:
      - crm-network

  # ── Aplicação de escrita ──────────────────────────────
  write-app:
    build: ./write-app
    container_name: crm-write-app
    ports:
      - "8080:8080"
    environment:
      SPRING_DATASOURCE_URL: jdbc:postgresql://db-write:5432/crm_write
      SPRING_DATASOURCE_USERNAME: crm
      SPRING_DATASOURCE_PASSWORD: crm
      SPRING_RABBITMQ_HOST: rabbitmq
      SPRING_RABBITMQ_PORT: 5672
    depends_on:
      - db-write
      - rabbitmq
    networks:
      - crm-network

  # ── Aplicação de leitura ──────────────────────────────
  read-app:
    build: ./read-app
    container_name: crm-read-app
    ports:
      - "8081:8080"
    environment:
      SPRING_DATASOURCE_URL: jdbc:postgresql://db-read:5432/crm_read
      SPRING_DATASOURCE_USERNAME: crm
      SPRING_DATASOURCE_PASSWORD: crm
      SPRING_RABBITMQ_HOST: rabbitmq
      SPRING_RABBITMQ_PORT: 5672
    depends_on:
      - db-read
      - rabbitmq
    networks:
      - crm-network

networks:
  crm-network:
    driver: bridge
